# Space Weather-Aware Anomaly Detection for CubeSats: A Systematic Ablation Study on Feature Fusion Strategies

This study investigates whether fusing space weather data with CubeSat telemetry improves anomaly detection, and whether the fusion architecture affects the outcome. Four model classes (Isolation Forest, Matrix Profile, Long Short-Term Memory Autoencoder, Temporal Convolutional Network Autoencoder) were evaluated under three fusion conditions (telemetry-only, naive concatenation, conditional asymmetric encoding) using the European Space Agency OPS-SAT Anomaly Detection benchmark aligned with National Oceanic and Atmospheric Administration space weather indices (Kp, Dst, F10.7, solar wind speed, proton density, interplanetary magnetic field Bz). Naive concatenation of space weather features degraded all four model classes, with statistically significant performance drops (p < 0.01 for all models). The Temporal Convolutional Network Autoencoder F1 score dropped from 0.604 to 0.222, a 63.2% relative decrease. Two failure mechanisms were identified: reconstruction error dilution in autoencoders and feature selection dilution in tree-based models. Conditional fusion, which encodes all channels but reconstructs only telemetry, recovered substantially but did not surpass telemetry-only baselines under the moderate storm conditions observed (Kp maximum 6.7). To our knowledge, the telemetry-only Temporal Convolutional Network Autoencoder F1 of 0.604 is the highest unsupervised result reported on this benchmark. These findings demonstrate that fusion architecture determines whether external features help or harm detection performance.
